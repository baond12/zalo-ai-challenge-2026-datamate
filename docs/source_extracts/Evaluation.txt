0001: Per-question scoring
0002: Each answer is scored correct, wrong or abstain. An answer of type abstain (or a missing answer) is an abstain. Any other answer is correct only if its type equals the reference type and its value matches the reference as follows; otherwise it is wrong. No partial credit.
0003: Type
0004: Answer content
0005: Example
0006: Matching rule
0007: number
0008: A numeric value (VND amounts, counts, quantities)
0009: 48250000
0010: Exact match. Reference values are integers (VND amounts, counts, quantities) or rounded to 2 decimals.
0011: percent
0012: A percentage value, in percent
0013: -12.45
0014: Exact match after rounding to 2 decimal places; the sign must be correct.
0015: string
0016: A name (product, customer, branch, weekday, ...)
0017: "Sting dâu 330ml"
0018: Both the answer and each accepted form of the reference are normalized, then compared for exact equality. Normalization: (1) Unicode NFC; (2) lowercase; (3) every character that is not a letter, a digit or whitespace is replaced by a space; (4) leading/trailing whitespace removed and runs of whitespace collapsed to one space. Diacritics are not removed. Each reference lists its accepted forms: every spelling of the name that occurs in that business’s data, plus its code — after normalization, e.g. sting dâu 330ml, sp0042.
0019: date
0020: A date in ISO format
0021: "2026-08-15", "2025-09"
0022: Exact match. yyyy-mm-dd; questions about a month: yyyy-mm (e.g. "2025-09").
0023: boolean
0024: true / false
0025: true
0026: Exact match.
0027: list
0028: An ordered list of names or numbers, in the order the question asks for (or the rulebook default)
0029: ["Cà phê sữa", "Bạc xỉu", "Trà đào"]
0030: Always ordered, and matched position by position. The order is the one the question asks for, or the rulebook default when the question gives none (see Ranking questions below). Elements are matched with the string or number rule.
0031: table
0032: A small table: column names and rows
0033: {"columns": [...], "rows": [[...], ...]}
0034: Columns are matched by normalized name; if the names do not match, by position. Rows are matched as a set; name cells with the stringrule, numeric cells with the number rule.
0035: unanswerable
0036: The data does not contain what is needed to answer
0037: —
0038: Correct if and only if the reference is unanswerable.
0039: abstain
0040: The agent chooses not to answer
0041: —
0042: Scored as abstain regardless of the reference.
0043: Ranking questions
0044: Rankings use the criterion stated in the question, or the rulebook default when the question gives none, in descending order of that criterion over valid orders only; elements with equal values are ordered by code, ascending. Questions whose reference ranking has a tie at the k boundary (or at rank 1 for “... nhất” questions) are excluded from the test sets. When fewer than k candidates exist, the reference answer is all of them.
0045: Score
0046: The leaderboard metric is Penalized Accuracy (PA) over the N questions of a test set:
0047: PA = (1 / N) × ∑(i = 1 to N) s_i
0048: s_i = 1, if answer i is correct
0049: s_i = 0, if answer i is abstain
0050: s_i = -1, if answer i is wrong
0051: Any answer given to an unanswerable question counts as wrong. All questions carry equal weight. Ties in the final ranking are broken by total inference time in the organizers’ re-run, then by earlier submission.
